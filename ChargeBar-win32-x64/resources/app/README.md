# HD2 ChargeBar

最新发布版本：**1.2.0**；main 新增的三把松手发射武器尚未发布运行包。仓库：[JunziSama/HD2CB](https://github.com/JunziSama/HD2CB)。

## 安装

当前目录已包含更新后的源码与 Windows 检测助手，直接运行 `ChargeBar.exe` 即可，无需安装 AutoHotkey。

启动后会出现托盘图标和启动通知。重复运行会提示“已在运行”，不会再创建另一套应用实例。Windows 的通知设置可能影响气泡是否显示，托盘图标始终是操作入口。

Electron 自身正常包含主进程、渲染进程等多个进程，另有一个 `FocusMonitor.exe`；这不代表重复启动。

## 使用

ChargeBar 是一个鼠标长按可视化提示工具，适用于游戏中武器能正常响应鼠标左键输入的场景。在极端情况下（如布娃娃状态），工具可能无法准确反映实际充能进度。

**显示模式**

点击或右键点击托盘图标选择显示模式，也可用默认 F1 循环切换：

- 隐藏：不显示充能提示条。
- 按住右键显示：HD2 位于前台且按住鼠标右键时显示（首次启动默认）。
- 游戏内常显：仅 HD2 位于前台时常显。

三种模式都受游戏焦点限制。切换到桌面、其他软件、最小化或退出游戏时会隐藏整个覆盖窗口，同时清空充能与左右键状态；切回游戏后需要重新按下鼠标。

默认 F2 退出程序。默认 F3 按“纪元 → 磁轨炮 → 类星体 → 电弧发射器 → 净化者 → 忠诚者 → 纪元”循环切换武器。**F1/F2/F3 仅在 HD2 前台时生效**，在其他软件中不会占用按键。也可以随时从托盘菜单退出。

**托盘与热键设置**

- 托盘可以分别开关“切换显示模式”、“退出程序”和“切换武器”热键。
- 双击托盘或选择“武器与热键设置…”打开中文设置窗口。关闭设置窗口不会退出程序。
- 点击快捷键输入框按下组合键，或输入/粘贴按键名称，保存后生效。
- 支持 F1–F24，或 Ctrl/Alt/Shift 加字母、数字、方向键、Enter、Space、Tab、Escape、Backspace、Delete、Insert、Home、End、PageUp、PageDown。
- 不接受重复绑定或 Windows 键。系统保留按键、被其他软件占用的按键会在游戏聚焦、尝试注册时提示冲突；可从托盘更换。
- “恢复默认”填入默认纪元和三项默认热键，需要点击保存。热键设置窗口不改变托盘中已选的显示模式。
- 配置保存于 `%APPDATA%\hd2-chargebar\settings.json`，包括武器、显示模式、热键及开关。重启后恢复；配置损坏时使用默认值并提示；保存失败则保留原设置。

**前台检测**

检测助手每 100 毫秒读取 Windows 前台窗口，优先匹配进程名 `helldivers2.exe`。仅在无法读取进程名时，兼容匹配精确窗口标题 `HELLDIVERS™ 2`。已知其他进程即使标题相同也不匹配。

参考 [GRW-CNChat v3](https://github.com/GameXueRen/GRW-CNChat/blob/main/GRW-CNChatv3.ahk) 的前台窗口判定思路，独立实现 C# 检测助手；未复制其 AutoHotkey 脚本。检测不读取或修改游戏内存，不注入游戏。

助手失败或超过 2 秒没有心跳时，进度条隐藏、热键释放，托盘显示异常。选择“重新检测”可恢复。工具正常退出或主进程异常终止后，助手会退出。

透明覆盖窗口建议在游戏窗口化或无边框模式下使用；独占全屏下的覆盖效果需实际验证。

**武器与充能提示**

main 新增电弧发射器（约 1 秒）、净化者（1 秒）、忠诚者（暂按 0.75 秒）：绿色蓄力，满格青色保持到松手，不安排隐藏计时，不添加伤害刻度。松手无论是否蓄满都立即清零；外框是否显示仍取决于显示模式。清零表示本轮计时结束，不判断游戏是否发射成功。失焦或切换武器清空，重新聚焦不恢复旧满格。

忠诚者时间采用更新记录，Wiki 详细表存在不一致，尚需真实游戏校准。配置版本仍为 2，保留已有选择与热键。

设置窗口保存武器选择后生效，也可从托盘单选菜单或默认 F3 切换。默认选择纪元，重启恢复上次选择。切换只改变提示配置，不操作游戏内武器；切换时清空旧充能，需要松开并重新按下左键。

| 武器 | 灰色 | 绿色 | 黄色 | 红色 | 上限 |
| --- | --- | --- | --- | --- | --- |
| PLAS-45 纪元 | 0–1 秒 | 1–2.5 秒 | 2.5–2.6 秒 | 2.6 秒起 | 3.25 秒 |
| RS-422 磁轨炮（不安全模式） | 0–0.45 秒 | 0.45–2 秒 | 2–2.5 秒 | 2.5 秒起 | 3 秒 |

类星体：0–3 秒绿色蓄力，3 秒满格变青，表示预计自动发射时点；不会过载自爆，不显示伤害阶段刻度或冷却计时。

纪元刻度对应 1 秒可发射、2.5 秒高穿甲、2.6 秒满伤害。磁轨炮 0.45 秒可发射；2 秒和 2.5 秒是本工具的高蓄力/危险区颜色提醒，不代表离散伤害档位。磁轨炮需在游戏内自行设为不安全模式。

资料：[纪元](https://helldivers.wiki.gg/wiki/Plas-45_Epoch)、[磁轨炮](https://helldivers.wiki.gg/wiki/Railgun)、[类星体](https://helldivers.wiki.gg/wiki/LAS-99_Quasar_Cannon)。计时依据鼠标输入，无法确认游戏实际充能、过载或是否处于安全模式。

原有纪元、磁轨炮、类星体在达到上限后保留满格完成提示 0.5 秒（纪元、磁轨炮为红色，类星体为青色），然后隐藏整个进度条，等待新的左键按下；常显和右键显示模式也遵循此规则。到顶前松开取消充能；到顶后松开不缩短完成提示，重新点击可立即开始新一轮。失焦时立即隐藏；已完成的等待状态不会因重新聚焦解除。

切换后在进度条右侧提示当前武器名 2 秒。切换时不可见则等到下一次进度条可见才开始计时；提示出现后若条隐藏，提示立即结束。连续切换仅保留最新名称。

旧版配置升级到版本 2 时保留原显示模式及两项热键，补入默认纪元和 F3；若 F3 已占用，选择 F4–F24 中首个空闲键。三项热键均可独立禁用，所有绑定统一检查重复。

## 开发与验证

保留现有 Electron 4.2.12、Node 10.11 和 iohook 0.9.2，不升级运行时。应用使用绝对资源路径，可从任意工作目录启动。

在 `resources/app` 目录执行：

```powershell
# 使用 Windows 自带 .NET Framework 4 编译器构建检测助手（交付目录已编译）
powershell -NoProfile -ExecutionPolicy Bypass -File native/build.ps1

# 状态、配置、托盘逻辑、助手心跳及异常退出测试；需要 Node.js
npm test

# 使用随附 Electron 实际启动，检查单实例、设置窗口、保存、恢复和退出
npm run test:smoke

# 可选交互测试：系统需要允许测试窗口取得前台焦点
npm run test:focus
```

实际启动测试在项目根目录 `.qa` 下使用独立运行时和配置，不修改用户设置。输出 JSON 检查报告和设置窗口截图。可选焦点测试还验证真实 Windows F3/F1 和自定义组合键，以及切出后的原生托盘菜单打开/关闭；测试按键仅在测试窗口处于前台时发送。阶段诊断写入 `hotkey-stages.log`，外部进程在卡死超时后保存 `timeout-*.json`。可选焦点测试使用名为 `helldivers2.exe` 的测试窗口，不是真实游戏；鼠标状态通过测试事件验证，不模拟系统鼠标输入。

开发依赖齐全时，`npm run dist` 会先构建助手，再重建 iohook 并打包。现有可运行目录无需重新打包即可使用。

iohook 0.9.2 在本机旧版 Electron 上主动 `unload()` 会发生原生崩溃；退出时停止 JS 事件分发并清理监听器，由 Windows 随进程退出释放原生钩子。

F3 卡死修复：切换武器/模式不再重新注册全局热键，操作在原生回调返回后执行；重复待处理事件合并，失焦、绑定变化和退出会取消过期操作。已有实例需要退出后重新启动才能加载更新。

真实游戏验收：在 HD2 窗口化/无边框模式中检查右键显示、常显、隐藏、充能途中 Alt+Tab、最小化、退出游戏、热键冲突和切回后重新按键。未运行真实游戏时，自动化检查不能替代这一步。
